# 📚 Online Book Store SQL Project

## 📖 Project Overview

This project analyzes an Online Book Store database using PostgreSQL. It includes basic and advanced SQL queries to extract meaningful business insights from book sales, customers, and orders.

---

## 🛠️ Tools & Technologies

- PostgreSQL
- pgAdmin 4
- SQL
- GitHub

---

## 📂 Dataset

The project uses three CSV files:

- Books.csv
- Customers.csv
- Orders.csv

- Customers
- Orders

## 📊 Project Questions Solved

### Basic Queries

- Retrieve Fiction books
- Books published after 1950
- Customers from Canada
- Orders placed in November 2023
- Total stock available
- Most expensive book
- Customers ordering more than one quantity
- Orders above \$20
- Available book genres
- Book with lowest stock
- Total revenue generated

### Advanced Queries

- Books sold by genre
- Average Fantasy book price
- Customers with at least two orders
- Most frequently ordered book
- Top 3 Fantasy books
- Quantity sold by each author
- Cities where customers spent over \$30
- Highest spending customer
- Remaining stock after fulfilling orders
