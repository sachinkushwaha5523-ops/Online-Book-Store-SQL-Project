# 📚 Online Book Store SQL Project

## Project Overview

This project demonstrates SQL skills using an Online Book Store dataset.

## Tools Used

- PostgreSQL
- pgAdmin 4
- GitHub

## Dataset

- Books.csv
- Customers.csv
- Orders.csv

## Topics Covered

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOINS
- Aggregate Functions
- LIMIT
- DISTINCT
- COALESCE

## SQL Questions Solved

✔ Basic Queries

- Retrieve Fiction books
- Books after 1950
- Customers from Canada
- November Orders
- Total Stock
- Most Expensive Book
- Total Revenue

✔ Advanced Queries

- Books sold by Genre
- Average Fantasy Price
- Customers with 2+ Orders
- Most Ordered Book
- Top 3 Fantasy Books
- Customer Spending
- Remaining Stock
